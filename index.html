Questions

Is Clarity free?

Yes. Clarity is free to use in your browser.

Does Clarity work offline?

Yes. Install it from your browser's install button, or use Add to Home Screen on an iPhone or iPad, and it keeps working without a connection. The one-click English voice needs a connection the first time you download it.

Which languages can Clarity read aloud?

English, French, Portuguese (Brazil), Spanish, German and Mandarin Chinese, using the voices on your device. If a voice is missing, Clarity tells you. For English, it can download a voice for you in one click.

What can I export?

Text (.txt), Markdown (.md) and PDF. An empty document can't be exported.
